Target Architecture

Seven principles
to build toward.

These principles should guide every configuration decision in Phase 1 and Phase 2.

HubSpot as Commercial System of Record

HubSpot governs contacts, companies, deals, activities, lifecycle, pipeline, campaign source and commercial reporting. It does not need to own every finance or delivery record.

Xero as Finance System of Record

Given existing Xero connections and invoice history, Xero should likely remain the finance source of truth, with HubSpot holding commercial and visibility data — subject to discovery validation.

Controlled Clay Enrichment

Clay should enrich selected segments through a pilot, with strict writeback rules, source tracking, confidence scoring and no uncontrolled overwrites of trusted HubSpot fields.

AI Inside Governed Workflows

AI should assist users and managers within clearly defined handoff rules — supporting qualification, summarisation, routing and follow-up drafts. Autonomous AI actions come later once data quality is stable.

Event Model Before ExpoFP

Mash must define event, edition, exhibitor, sponsor and product relationships inside HubSpot before building any floor plan integration. Architecture first, integration second.

Reporting from Governed Process

Dashboards should be built only after required fields, associations and stage rules are defined. Building reports before governance simply exposes data quality problems on a screen.

Integration Governance Before Expansion

Existing connected apps, Xero integrations and private apps must be reviewed and rationalised before adding new automation or middleware. Adding complexity before resolving existing issues creates compounding risk.
